FAQ

        
常见问题

      

      

        

          为什么当前是「演示模式」？如何接入真实解析？
          
平台接口普遍存在防盗链与风控，浏览器直连无法完成解析，需要服务器转发。为方便体验，本页面内置了本地演示引擎：解析流程、平台识别、预览播放、下载与超分均为真实可用的完整交互，但视频内容为本地生成的示例片源。接入真实服务：将 js/app.js 顶部 API.endpoint 改为你的解析服务地址，并按 README.md 中的协议返回 JSON 即可，前端无需其他改动。

        

        

          支持哪些平台？解析后是原画质吗？
          
已内置抖音 / TikTok、快手、B站、小红书、微博、视频号、西瓜、皮皮虾等主流平台识别规则，可自由扩展。真实接入后默认返回平台无水印源画质（原画 / 高清直链）；演示模式下为 640×360 示例片源，可用超分增强至 720P / 1440P。

        

        

          超分（Super Resolution）是怎么实现的？
          
页面内置超分工作台：演示模式下用本地渲染引擎对片源进行 2× / 4× 真实重绘增强（生成的文件分辨率、体积会真实变化），用于完整走通交互链路；接入后端后可将任务转发给 Real-ESRGAN / Waifu2x 等模型服务，前端交互无需改动。

        

        

          下载的文件是什么格式？可以商用吗？
          
演示模式下载 WebM 视频与 PNG 封面；真实服务可配置为 MP4 / 封面 / 音频等资产。请仅用于个人学习、备份与二次创作素材，不得搬运商用或恶意抹除版权信息牟利，发布前请遵守各平台版权规则。

        

        

          解析记录保存在哪里？会泄露隐私吗？
          
历史记录仅存于浏览器 localStorage（本机），不会上传任何服务器；演示模式不发起任何网络请求，所有内容在本地生成。接入真实服务后，请求仅发往你配置的解析接口。
